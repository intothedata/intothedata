# GitHub Pages 배포 전환

## 작업 일시
2026-11-04 23:30

## 작업 내용
- intothedata.com 을 Contabo 서버에서 빼고 GitHub Pages 로 옮겼다. 정적 사이트라 서버 자원이 필요 없다.
- 배포 워크플로(.github/workflows/main.yml)를 self-hosted runner 방식에서 GitHub Pages 방식으로 바꿨다.
  - GitHub 호스팅 러너에서 Hugo 0.123.8 extended 로 빌드 → actions/deploy-pages 로 배포한다.
  - Contabo self-hosted runner 방식은 로컬에서만 수정되고 push 되지 않은 상태였다(등록된 러너 없음).
- intothedata 계정이 무료 플랜이라 비공개 저장소로는 Pages 를 쓸 수 없어 저장소를 공개로 전환했다.
  - 전환 전에 비밀 정보를 검사했다. master 와 그 이력에는 실제 비밀번호가 없었다(과거 database.php 는 빈 값).
- euriion/intothedata_php(2021 PHP 버전)를 이 계정으로 합쳤다.
  - 설정 파일에 비밀번호가 있어서 별도 비공개 저장소 intothedata/intothedata-php-archive 로 두었다.
  - euriion/intothedata_php 는 삭제했다.
- 사이트 제목·부제·첫 화면 문구를 "데이터과학 학습/책장" 컨셉으로 바꾼 미커밋 수정을 함께 커밋했다.
