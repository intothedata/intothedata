    온라인 광고 용어 )Online Ad Terminology) #

    디지털 광고 산업 용어 #

    디지털 광고 산업은 전통적인 마케팅과 세일즈 영역과 밀접하게 연결되어 있어, 관련 용어들이 복합적으로 사용되고 있다. 현대에는 온라인 마케팅을 전통적인 마케팅과 분리해서 운영할 수 없는 상황이 되었으며, 디지털 광고는 가장 강력한 마케팅 수단 중 하나로 자리잡았다. 디지털 마케팅 시장과 산업이 지속적으로 성장하고 있는 만큼, 이러한 용어들은 디지털 마케팅뿐만 아니라 전체 마케팅 생태계에서 광범위하게 활용되고 있다.

    CPM (Cost per Mille) #

    정의: 광고 1,000회 노출(Impression)당 지불하는 비용을 의미한다.

    특징:

    • 브랜드 인지도 향상을 목적으로 하는 캠페인에 주로 사용
    • 노출 횟수 기준으로 과금되므로 클릭이나 전환과 무관하게 비용 발생
    • 대규모 브랜딩 캠페인에서 효과적

    계산 공식: CPM = (총 광고비 ÷ 총 노출 수) × 1,000

    CPC (Cost per Click) #

    정의: 광고 클릭 1회당 지불하는 비용을 의미한다.

    특징:

    • 실제 사용자의 관심과 행동을 기반으로 과금
    • 트래픽 유도와 웹사이트 방문 증대에 효과적
    • 검색 광고와 디스플레이 광고에서 널리 사용

    장점:

    • 실제 클릭에 대해서만 비용 지불
    • ROI 측정이 상대적으로 용이
    • 예산 통제가 효율적

    CPI (Cost per Install) #

    정의: 모바일 앱 설치 1회당 지불하는 비용을 의미한다.

    특징:

    • 모바일 앱 마케팅에서 주로 사용되는 과금 모델
    • 실제 앱 설치가 완료되었을 때만 비용 지불
    • 앱 다운로드 수 증가를 목적으로 하는 캠페인에 효과적

    활용 분야:

    • 게임 앱의 신규 사용자 확보
    • 유틸리티 앱의 사용자 기반 확장
    • 브랜드 앱의 초기 런칭 단계

    계산 공식: CPI = 총 광고비 ÷ 총 설치 수

    CPA (Cost per Action/Acquisition) #

    정의: 특정 행동(Action) 또는 고객 획득(Acquisition) 1회당 지불하는 비용을 의미한다.

    특징:

    • 광고주가 원하는 구체적인 목표 달성 시에만 과금
    • 가장 성과 중심적인 과금 모델
    • ROI 측정과 예산 효율성이 높음

    주요 액션 유형:

    • 회원가입: 신규 회원 등록 완료
    • 구매 완료: 실제 상품/서비스 구매
    • 문의 신청: 상담 요청이나 견적 문의
    • 앱 내 구매: 인앱 결제 완료
    • 뉴스레터 구독: 이메일 구독 신청

    장점:

    • 명확한 성과 측정 가능
    • 광고 예산의 효율적 활용
    • 비즈니스 목표와 직접적 연관

    계산 공식: CPA = 총 광고비 ÷ 총 액션 수

    DMP (Data Management Platform) #

    정의: 다양한 소스로부터 수집된 데이터를 통합, 관리, 분석하여 광고 타겟팅에 활용할 수 있는 플랫폼이다.

    주요 기능:

    • 데이터 수집: 웹사이트, 모바일 앱, CRM 등 다양한 채널에서 데이터 수집
    • 데이터 통합: 서로 다른 형태의 데이터를 표준화하여 통합
    • 세그멘테이션: 사용자 행동과 특성에 따른 세그먼트 생성
    • 오디언스 생성: 타겟팅 목적에 맞는 맞춤형 오디언스 구축

    데이터 처리 과정:

    1. 쿠키 ID, 디바이스 ID 등을 통한 비식별 데이터 수집
    2. 기계학습과 통계 분석을 통한 사용자 패턴 분석
    3. “일본 여행 관심자”, “럭셔리 브랜드 선호자” 등의 세그먼트 생성
    4. 광고주나 다른 플랫폼과의 데이터 교환 및 판매

    개인정보보호: 개인 식별 정보가 아닌 쿠키 기반의 비식별 데이터를 사용하므로, 데이터의 수명이 상대적으로 짧아 지속적인 모니터링과 업데이트가 필요하다.

    옴니채널 쇼퍼 (Omni-channel Shopper) #

    정의: 온라인과 오프라인을 구분하지 않고 다양한 채널을 자유롭게 넘나들며 쇼핑하는 소비자를 의미한다.

    옴니채널의 특징:

    • 채널 통합: 오프라인 매장, 온라인 쇼핑몰, 모바일 앱, TV 쇼핑 등 모든 채널에서 동일한 제품과 서비스 제공
    • 일관된 경험: 채널에 관계없이 동일한 가격, 프로모션, 고객 서비스 제공
    • 데이터 연동: 모든 채널에서의 고객 행동 데이터가 통합 관리

    쇼핑 행동 예시:

    • 오프라인 매장에서 제품을 체험하고 온라인에서 구매 (쇼루밍)
    • 온라인에서 정보를 수집하고 오프라인 매장에서 구매 (웹루밍)
    • 모바일로 주문하고 매장에서 픽업
    • 다양한 채널을 통해 동일한 고객 서비스 이용

    형상화 (Imagery) #

    정의: 추상적이거나 무형의 제품/서비스를 시각적으로 구체화하여 소비자가 쉽게 이해하고 기억할 수 있도록 표현하는 마케팅 기법이다.

    필요성:

    • 유형 제품과 달리 무형 서비스는 직접적인 시각적 표현이 어려움
    • 소비자의 이해도와 기억도 향상
    • 브랜드 이미지와 가치 전달의 효율성 증대

    적용 분야:

    • 교육 서비스: 온라인 강의를 책, 졸업장, 성공한 사람의 이미지로 표현
    • 컨설팅: 전문가의 모습, 성장 그래프, 성공 사례로 시각화
    • 피트니스: 건강한 몸매, 운동하는 모습, 변화 전후 비교로 표현
    • 관광: 아름다운 풍경, 즐거운 여행객, 특색 있는 문화로 형상화

    효과적인 형상화 전략:

    • 타겟 고객의 니즈와 감정에 어필하는 이미지 선택
    • 브랜드 아이덴티티와 일관성 있는 시각적 표현
    • 문화적 배경과 트렌드를 고려한 이미지 활용

    사용자 트래킹 (User Tracking) #

    정의: 사용자의 온라인 행동을 추적하고 기록하여 개인화된 광고 타겟팅과 마케팅 최적화에 활용하는 기술이다. 웹사이트 방문, 클릭, 구매, 검색 등 디지털 환경에서의 모든 사용자 활동을 수집하고 분석한다.

    트래킹 기술의 종류 #

    1. 쿠키 기반 트래킹 (Cookie-based Tracking) #

    퍼스트 파티 쿠키 (First-party Cookies):

    • 사용자가 직접 방문한 웹사이트에서 생성하는 쿠키
    • 로그인 상태 유지, 장바구니 정보 저장 등에 활용
    • 상대적으로 개인정보보호 이슈가 적음
    • 브라우저 정책 변화에도 상대적으로 안전

    서드 파티 쿠키 (Third-party Cookies):

    • 사용자가 방문한 웹사이트가 아닌 외부 도메인에서 생성하는 쿠키
    • 여러 웹사이트에 걸친 사용자 행동 추적 가능
    • 광고 네트워크와 애드테크 업체들이 주로 활용
    • 개인정보보호 강화로 점진적 폐지 예정 (Chrome 2024년 완전 차단)

    2. 디바이스 핑거프린팅 (Device Fingerprinting) #

    기술적 원리:

    • 브라우저 정보, 화면 해상도, 설치된 폰트, 플러그인 등을 조합
    • 각 디바이스의 고유한 “지문"을 생성하여 식별
    • 쿠키 없이도 사용자 추적 가능

    수집 정보:

    • 운영체제 및 브라우저 버전
    • 화면 해상도 및 색상 깊이
    • 시간대 및 언어 설정
    • 설치된 폰트 목록
    • 하드웨어 사양 (GPU, CPU 등)

    3. 모바일 식별자 #

    IDFA (Identifier for Advertisers):

    • iOS 기기의 광고 식별자
    • 사용자가 직접 리셋하거나 추적 거부 가능
    • iOS 14.5부터 앱 추적 투명성(ATT) 정책으로 사용자 동의 필수

    GAID (Google Advertising ID):

    • Android 기기의 광고 식별자
    • 구글 플레이 서비스를 통해 관리
    • 사용자가 설정에서 리셋하거나 개인화 광고 거부 가능

    트래킹 데이터의 활용 #

    사용자 프로파일 구축 #

    • 인구통계학적 정보: 연령, 성별, 지역 추정
    • 관심사 분석: 방문 웹사이트와 콘텐츠 기반 관심사 도출
    • 구매 패턴: 쇼핑 행동, 가격 민감도, 브랜드 선호도 분석
    • 라이프스타일: 온라인 활동 시간, 디바이스 사용 패턴 등

    개인화 광고 타겟팅 #

    • 행동 타겟팅: 과거 행동 기반 광고 노출
    • 예측 타겟팅: 기계학습을 통한 미래 행동 예측
    • 룩얼라이크 타겟팅: 유사한 특성을 가진 사용자 그룹 발견
    • 크로스 디바이스 타겟팅: 여러 기기에 걸친 통합 타겟팅
