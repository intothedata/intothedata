## 데이터시각화 개요

데이터를 시각적으로 표현하는 것을 데이터 시각화(Data Visualization)이라고 한다.

데이터시각화는 단순하게 차트를 그리는 것을 말하는 것은 아니다. 
데이터를 잘 이해하고 인사이트를 잘 찾아낼 수 있게 데이터를 적절하고 효과적으로 표현하는 행위, 기술을 말한다.

데이터시각화에서 그리는 도표는 흔히 차트라고 불리는 것 보다는 플롯이라고 불리는 복잡한 것들이 많다.  
차트는 1개 또는 2개 정도의 차원의 데이터를 표현해서 쉽게
