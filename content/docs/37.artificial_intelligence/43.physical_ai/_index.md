## 피지컬 AI (Physical AI)

피지컬 AI는 **현실 세계를 감지하고, 이해하고, 직접 움직여서 일을 하는 AI**를 말한다. 화면 속에서 글이나 그림을 만드는 AI가 아니라, 로봇·자율주행차·드론·스마트 공장처럼 **몸(하드웨어)을 가지고 물리 세계와 부딪치는 AI** 전체를 가리킨다.

예를 들어 물류 창고에서 처음 보는 모양의 상자를 집어 분류하는 로봇 팔, 공사장 계단을 오르내리는 휴머노이드(사람 모양 로봇), 비 오는 밤 골목길을 달리는 자율주행차가 모두 피지컬 AI다.

### 용어의 배경

비슷한 개념은 오래전부터 **체화된 AI (Embodied AI)**라는 이름으로 연구되어 왔다. "피지컬 AI"라는 말은 2024~2025년 NVIDIA가 [LLM]({{< relref "/docs/37.artificial_intelligence/39.large_language_model" >}}) 다음 단계의 AI로 강조하면서 산업계에 널리 퍼졌다. 생성형 AI가 "디지털 세계의 지능"이라면, 피지컬 AI는 "현실 세계의 지능"이라는 구분이다.

## 생성형 AI와 무엇이 다른가

| 구분 | 생성형 AI (LLM, VLM 등) | 피지컬 AI |
|---|---|---|
| 일하는 곳 | 화면, 디지털 공간 | 현실 공간 |
| 출력 | 글, 이미지, 코드 | 움직임, 힘, 조작 |
| 실수의 대가 | 다시 생성하면 됨 | 물건 파손, 사람 안전 문제 |
| 반응 속도 | 몇 초 기다려도 괜찮음 | 수십 밀리초 안에 반응해야 함 |
| 학습 데이터 | 인터넷 글·이미지가 풍부 | 실제 동작 데이터가 매우 부족 |
| 지켜야 할 것 | 사실성, 문맥 | 중력, 마찰, 관성 같은 물리 법칙 |

## 피지컬 AI를 이루는 기술

피지컬 AI는 한 가지 모델이 아니라 여러 기술의 묶음이다. "보고 → 이해하고 → 계획하고 → 움직이는" 순환을 끊임없이 반복한다.

```
     ┌──────────── 현실 세계 ◀────────────┐
     ▼                                      │
 [감지] 카메라·라이다·촉각 센서             │
     ▼                                      │
 [이해] VLM, 3D 인식, 상태 추정             │
     ▼                                      │
 [계획] LLM 추론, 월드 모델로 결과 예측     │
     ▼                                      │
 [행동] VLA, 로봇 제어기 ──▶ 모터·관절 ────┘
```

### 1. 인식 (Perception)

카메라, 라이다(LiDAR, 레이저로 거리를 재는 센서), 깊이 센서, 촉각 센서로 주변을 파악한다. [VLM]({{< relref "/docs/37.artificial_intelligence/41.vision_language_model" >}})이 "저건 깨지기 쉬운 유리컵"처럼 의미까지 이해하는 역할을 맡는다.

### 2. 행동 모델 (Action Model)

[VLA]({{< relref "/docs/37.artificial_intelligence/42.vision_language_action" >}})처럼 보고 들은 것을 바로 동작으로 바꾸는 모델이다. 피지컬 AI의 "두뇌와 손을 잇는 신경"에 해당한다.

### 3. 월드 모델 (World Model)

**"이렇게 움직이면 세상이 어떻게 변할까?"를 머릿속으로 미리 그려 보는 모델**이다. 예를 들어 컵을 너무 세게 밀면 넘어진다는 것을 실제로 해 보기 전에 예측한다. 영상 생성 기술을 응용해 다음 장면을 만들어 내는 방식이 많이 연구되며, NVIDIA Cosmos, Google DeepMind Genie 등이 대표적이다. 로봇 학습용 가상 데이터를 만드는 데도 쓰인다.

### 4. 시뮬레이션과 디지털 트윈 (Simulation & Digital Twin)

현실 공장이나 창고를 가상 공간에 똑같이 만든 것을 디지털 트윈이라 한다. 로봇은 가상 공간에서 수백만 번 넘어지고 실패하며 먼저 배운 뒤 현실로 나온다. NVIDIA Isaac Sim / Omniverse, MuJoCo 등이 쓰인다.

- **Sim-to-Real**: 가상에서 배운 것을 현실에 옮기는 과정. 가상과 현실의 차이(조명, 마찰, 센서 잡음)를 줄이기 위해 가상 환경의 조건을 일부러 무작위로 바꿔 가며 학습시킨다(Domain Randomization).

### 5. 강화학습과 모방학습

- **모방학습 (Imitation Learning)**: 사람의 시범을 보고 따라 배운다. VLA 학습의 기본.
- **강화학습 (Reinforcement Learning)**: 시행착오와 보상으로 배운다. 걷기, 균형 잡기처럼 시범을 보이기 어려운 동작을 시뮬레이션에서 익힐 때 강하다.

### 6. 엣지 컴퓨팅 (Edge Computing)

로봇은 인터넷이 끊겨도, 0.1초 안에 반응해야 한다. 그래서 클라우드가 아니라 로봇 몸 안의 칩에서 모델을 돌리는 기술(경량화, 양자화, 전용 칩)이 중요하다.

## 적용 분야

- **휴머노이드 로봇**: 사람이 일하던 공간과 도구를 그대로 쓰기 위해 사람 모양으로 만든 범용 로봇. 공장, 물류, 가사 분야에서 시범 도입이 늘고 있다.
- **산업용 로봇·물류**: 정해진 위치만 반복하던 로봇이, 처음 보는 물건도 집고 분류하도록 바뀌는 중이다.
- **자율주행**: 카메라 영상만으로 운전 판단까지 하나의 모델로 처리하는 종단간(End-to-End) 방식이 확산되고 있다.
- **드론·농업·건설**: 작물 상태 판별, 현장 점검, 위험 지역 작업.
- **의료·돌봄**: 수술 보조 로봇, 재활 보조, 돌봄 로봇.

## 데이터과학 관점에서 보면

피지컬 AI는 결국 **데이터 문제**이기도 하다.

- **데이터 수집 설계**: 어떤 상황의 시연 데이터를 얼마나 모을지가 모델 성능을 좌우한다. 실패 사례와 드문 상황(엣지 케이스)을 의도적으로 모아야 한다.
- **센서 데이터 처리**: 영상, 관절 각도, 힘, 위치 같은 서로 다른 시계열을 시간축에 정확히 맞추는 일이 기본이다.
- **합성 데이터**: 시뮬레이션과 월드 모델로 만든 가짜 데이터가 실제 데이터를 얼마나 대신할 수 있는지 검증해야 한다.
- **평가와 실험 설계**: 성공률을 믿을 만하게 재려면 반복 실험 횟수, 조건 통제, 통계적 비교가 필요하다.

## 한계와 과제

- **데이터 부족**: LLM이 인터넷 전체를 학습한 것과 달리, 로봇 동작 데이터는 아직 턱없이 적다.
- **안전과 신뢰성**: 99% 성공해도 1%의 실패가 사고로 이어질 수 있다. 안전 기준과 인증 체계가 아직 정비 중이다.
- **하드웨어 비용과 내구성**: 정밀한 손, 배터리, 센서가 비싸고 고장이 잦다.
- **일반화**: 연구실에서는 되지만 실제 가정이나 공장의 다양한 환경에서는 실패하는 경우가 많다.
- **사회적 영향**: 일자리 변화, 사생활(로봇의 카메라), 책임 소재(사고가 나면 누구 책임인가) 문제.

## LLM에서 피지컬 AI까지 한눈에

1. **[LLM]({{< relref "/docs/37.artificial_intelligence/39.large_language_model" >}})** — 글을 이해하고 글로 답한다.
2. **[VLM]({{< relref "/docs/37.artificial_intelligence/41.vision_language_model" >}})** — 이미지를 보고 글로 답한다.
3. **[VLA]({{< relref "/docs/37.artificial_intelligence/42.vision_language_action" >}})** — 보고 듣고 로봇 동작으로 답한다.
4. **피지컬 AI** — VLA에 센서, 월드 모델, 시뮬레이션, 하드웨어를 합쳐 현실에서 일한다.
