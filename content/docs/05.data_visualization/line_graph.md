## 선그래프 (Line Graph)

선그래프는 시간의 흐름에 따른 데이터의 변화나 연속적인 변수 간의 관계를 선으로 연결하여 표현하는 데이터 시각화 방법이다. 영어로는 Line Graph, Line Chart, 또는 Line Plot이라고 부른다.

### 선그래프의 정의와 구조

선그래프는 다음과 같은 구조로 이루어진다:

**1. 수평축 (X축)**
- 일반적으로 시간(연도, 월, 일 등) 또는 순서가 있는 연속적인 변수
- 독립변수(Independent Variable)를 나타냄
- 등간격으로 눈금이 표시됨

**2. 수직축 (Y축)**
- 측정하고자 하는 값(종속변수, Dependent Variable)
- 온도, 매출액, 인구수, 주가 등 수치형 데이터
- 데이터의 범위에 맞게 적절한 척도로 설정

**3. 데이터 포인트 (Data Points)**
- 각 시점에서의 측정값을 나타내는 점
- 좌표평면 상에서 (x, y) 값으로 표현

**4. 연결선 (Connecting Lines)**
- 인접한 데이터 포인트들을 직선으로 연결
- 데이터의 연속성과 변화 추세를 시각적으로 표현

### 선그래프의 주요 특징과 장점

**1. 추세 파악 용이성**
- 시간에 따른 증가, 감소, 변동 패턴을 명확하게 보여줌
- 장기적인 트렌드와 단기적인 변동을 동시에 관찰 가능
- 계절성이나 주기적 패턴 식별에 효과적

**2. 연속성 표현**
- 데이터 포인트 간의 연결을 통해 연속적인 변화 과정 시각화
- 중간값 추정이나 보간(interpolation) 개념 이해에 도움
- 데이터의 흐름과 방향성을 직관적으로 파악

**3. 비교 분석 가능**
- 여러 개의 선을 하나의 그래프에 그려 비교 분석
- 서로 다른 그룹이나 변수 간의 변화 패턴 비교
- 상관관계나 인과관계 탐색에 유용

### 선그래프의 활용 분야와 사례

**1. 경제 및 금융 분야**
- 주가 변동, GDP 성장률, 인플레이션율 추이
- 환율 변화, 금리 변동, 경제지표 분석
- 기업의 매출액, 순이익 변화 추적

**2. 과학 및 연구 분야**
- 실험 결과의 시간별 변화 관찰
- 기후 데이터(온도, 강수량, 습도) 분석
- 인구 증감, 질병 발생률 추이 연구

**3. 비즈니스 및 마케팅**
- 웹사이트 방문자 수, 매출 추이 분석
- 제품 판매량, 시장 점유율 변화
- 고객 만족도, 브랜드 인지도 변화 추적

### 선그래프의 종류

**1. 단일 선그래프 (Single Line Graph)**
- 하나의 변수에 대한 시간별 변화를 표현
- 가장 기본적이고 간단한 형태

**2. 다중 선그래프 (Multiple Line Graph)**
- 여러 변수나 그룹을 하나의 그래프에서 비교
- 서로 다른 색상이나 선 스타일로 구분

**3. 누적 선그래프 (Stacked Line Graph)**
- 여러 변수의 누적값을 표현
- 전체 합계와 각 구성요소의 기여도를 동시에 파악

### 선그래프 작성 시 주의사항

**1. 축 설정**
- Y축의 시작점을 0으로 설정하여 왜곡 방지
- 적절한 축 범위 설정으로 데이터 패턴 명확화
- 축 레이블과 단위 명시

**2. 데이터 포인트 표시**
- 중요한 데이터 포인트는 점으로 명확히 표시
- 데이터가 부족한 구간에서는 점선 사용 고려
- 이상치나 특이점에 대한 설명 추가

**3. 가독성 향상**
- 선의 색상과 스타일을 구분하여 혼동 방지
- 범례(Legend) 추가로 각 선의 의미 명확화
- 그래프 제목과 축 제목으로 내용 설명

### 선그래프와 다른 시각화 방법과의 비교

**선그래프 vs 막대차트**
- 선그래프: 연속적인 변화, 시간 순서가 중요한 데이터
- 막대차트: 범주별 비교, 시점별 독립적인 값

**선그래프 vs 산점도**
- 선그래프: 순서가 있는 데이터, 추세 파악 중심
- 산점도: 두 변수 간의 상관관계 분석 중심
