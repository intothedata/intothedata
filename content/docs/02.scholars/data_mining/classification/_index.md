## 분류 (Classification)

분류(Classification)는 데이터마이닝과 기계학습에서 가장 널리 사용되는 지도학습(Supervised Learning) 기법 중 하나입니다. 분류의 목적은 주어진 데이터(입력, feature)가 어떤 범주(클래스, class)에 속하는지 예측하는 것입니다. 즉, 이미 정답(레이블, label)이 주어진 데이터를 바탕으로 학습하여, 새로운 데이터가 들어왔을 때 그 데이터가 어떤 클래스에 속하는지 자동으로 판별하는 모델을 만드는 과정입니다.

### 분류의 예시

- 이메일이 스팸인지 아닌지 판별(스팸 필터링)
- 사진 속 동물이 고양이인지 개인지 구분
- 환자의 진단 결과가 질병 유무로 분류
- 고객이 상품을 구매할지 여부 예측

### 분류의 주요 알고리즘

- **의사결정나무(Decision Tree)**
- **로지스틱 회귀(Logistic Regression)**
- **나이브 베이즈(Naive Bayes)**
- **서포트 벡터 머신(SVM)**
- **k-최근접 이웃(k-NN)**
- **신경망(Neural Network)**
- **랜덤 포레스트(Random Forest), 부스팅(Boosting) 등 앙상블 기법**

### 분류의 절차

1. **데이터 수집 및 전처리**: 입력 데이터와 정답(레이블) 준비, 결측치 처리, 특성 선택 등
2. **모델 학습(Training)**: 학습 데이터를 이용해 분류 모델을 학습
3. **모델 평가(Evaluation)**: 테스트 데이터를 이용해 모델의 성능(정확도, 정밀도, 재현율 등) 평가
4. **예측(Prediction)**: 새로운 데이터에 대해 분류 결과 예측

### 분류와 회귀의 차이

분류는 결과가 미리 정의된 범주(예: 스팸/비스팸, 질병/무질병 등)로 나누는 문제이고, 회귀(Regression)는 연속적인 수치 값을 예측하는 문제입니다.

### 참고

분류는 실제 산업, 의료, 금융, 마케팅 등 다양한 분야에서 활용되며, 데이터마이닝의 핵심적인 분석 기법 중 하나입니다. 분류 문제를 잘 해결하기 위해서는 데이터의 특성, 적절한 알고리즘 선택, 성능 평가 방법에 대한 이해가 중요합니다.

## 분류(Classification)

분류(Classification)는 주어진 데이터가 어떤 범주(클래스)에 속하는지 예측하는 지도학습(Supervised Learning) 기법이다. 즉, 입력 데이터에 대해 미리 정의된 여러 클래스 중 하나로 분류하는 것이 목표다.

분류 문제는 대표적으로 이메일 스팸 필터링(스팸/비스팸), 질병 진단(양성/음성), 이미지 인식(고양이/개/자동차 등), 고객 이탈 예측(이탈/비이탈) 등 다양한 분야에서 활용된다.

분류 알고리즘은 크게 이진 분류(Binary Classification)와 다중 분류(Multi-class Classification)로 나뉜다. 이진 분류는 두 개의 클래스로 구분하는 문제이고, 다중 분류는 세 개 이상의 클래스로 구분하는 문제다.

대표적인 분류 알고리즘으로는 다음과 같은 것들이 있다.

- **로지스틱 회귀(Logistic Regression)**: 확률 기반의 선형 분류 기법이다.
- **의사결정나무(Decision Tree)**: 데이터의 특징을 기준으로 트리를 만들어 분류한다.
- **랜덤 포레스트(Random Forest)**: 여러 개의 의사결정나무를 앙상블하여 예측 성능을 높인다.
- **서포트 벡터 머신(SVM)**: 데이터 간의 경계(초평면)를 찾아 분류한다.
- **k-최근접 이웃(k-NN)**: 가장 가까운 k개의 이웃 데이터를 참고하여 분류한다.
- **신경망(Neural Network)**: 복잡한 패턴을 학습할 수 있는 딥러닝 기반 분류 기법이다.

분류 모델의 성능 평가는 정확도(Accuracy), 정밀도(Precision), 재현율(Recall), F1 점수(F1 Score), ROC-AUC 등 다양한 지표를 사용한다. 데이터의 불균형, 과적합, 특성 선택 등도 분류 문제에서 중요한 고려사항이다.

실제 분류 문제를 해결할 때는 데이터 전처리, 특성 엔지니어링, 모델 선택 및 하이퍼파라미터 튜닝, 성능 평가의 과정을 체계적으로 수행하는 것이 중요하다.
