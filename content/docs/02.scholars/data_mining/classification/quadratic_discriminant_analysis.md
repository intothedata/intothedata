## 이차 판별 분석 (Quadratic Discriminant Analysis, QDA)

이차 판별 분석(Quadratic Discriminant Analysis, QDA)은 선형 판별 분석(LDA)을 확장한 분류 알고리즘으로, 각 클래스가 서로 다른 공분산 행렬을 가질 수 있다고 가정한다. 이로 인해 결정 경계가 이차 함수(quadratic function) 형태가 되어 더 복잡한 패턴을 포착할 수 있다.

### QDA의 기본 개념

#### 1. LDA와의 차이점
- **LDA**: 모든 클래스가 동일한 공분산 행렬 가정
- **QDA**: 각 클래스마다 서로 다른 공분산 행렬 허용

#### 2. 결정 경계
- **LDA**: 선형 결정 경계
- **QDA**: 이차 곡선 형태의 결정 경계

### QDA의 수학적 원리

#### 1. 베이즈 정리 기반

각 클래스 k에 대한 사후 확률:
$$P(Y = k|X = x) = \frac{P(X = x|Y = k) \cdot P(Y = k)}{P(X = x)}$$

#### 2. 다변량 정규분포 가정

클래스 k의 우도 함수:
$$P(X = x|Y = k) = \frac{1}{(2\pi)^{p/2}|\Sigma_k|^{1/2}} \exp\left(-\frac{1}{2}(x - \mu_k)^T\Sigma_k^{-1}(x - \mu_k)\right)$$

여기서:
- $\mu_k$: 클래스 k의 평균 벡터
- $\Sigma_k$: 클래스 k의 공분산 행렬
- $p$: 특성의 개수

#### 3. 판별 함수

클래스 k에 대한 이차 판별 함수:
$$g_k(x) = -\frac{1}{2}(x - \mu_k)^T\Sigma_k^{-1}(x - \mu_k) - \frac{1}{2}\log|\Sigma_k| + \log P(Y = k)$$

분류 규칙:
$$\hat{Y} = \arg\max_k g_k(x)$$

### QDA의 장점

1. **유연성**: 복잡한 결정 경계 형성 가능
2. **클래스별 분산**: 각 클래스의 고유한 분산 구조 반영
3. **비선형 분류**: 선형으로 분리되지 않는 데이터 처리 가능
4. **확률적 해석**: 각 클래스에 대한 확률 정보 제공
5. **베이즈 최적**: 가정이 맞을 때 베이즈 최적 분류기

### QDA의 단점

1. **매개변수 증가**: 클래스별 공분산 행렬로 인한 많은 매개변수
2. **과적합 위험**: 작은 데이터셋에서 과적합되기 쉬움
3. **계산 복잡도**: 각 클래스별 역행렬 계산 필요
4. **정규분포 가정**: 데이터가 정규분포를 따른다는 강한 가정
5. **특이행렬 문제**: 공분산 행렬이 특이행렬일 때 문제 발생

### QDA vs LDA 비교

#### 매개변수 수
- **LDA**: $K \times p + \frac{p(p+1)}{2}$ (공통 공분산 행렬)
- **QDA**: $K \times p + K \times \frac{p(p+1)}{2}$ (클래스별 공분산 행렬)

여기서 K는 클래스 수, p는 특성 수이다.

#### 편향-분산 트레이드오프
- **LDA**: 높은 편향, 낮은 분산
- **QDA**: 낮은 편향, 높은 분산

#### 사용 지침
- **LDA 선택**: 데이터가 적거나 클래스별 공분산이 유사할 때
- **QDA 선택**: 데이터가 충분하고 클래스별 분산 구조가 다를 때

### 정규화된 판별 분석 (RDA)

LDA와 QDA의 절충안으로, 정규화 매개변수 α를 도입:

$$\Sigma_k(\alpha) = \alpha \Sigma_k + (1-\alpha) \Sigma$$

여기서:
- α = 0: LDA와 동일
- α = 1: QDA와 동일
- 0 < α < 1: LDA와 QDA의 중간 형태

### 실제 적용 예시

#### 1. 금융 분야
- **신용 위험 평가**: 다양한 고객 그룹의 서로 다른 위험 프로파일
- **포트폴리오 분류**: 투자 성향별 다른 변동성 패턴

#### 2. 의료 진단
- **질병 분류**: 질병별로 다른 증상 패턴의 분산
- **영상 진단**: 병변의 형태학적 차이

#### 3. 마케팅
- **고객 세분화**: 세그먼트별 다른 행동 패턴
- **제품 분류**: 카테고리별 다른 특성 분포

#### 4. 패턴 인식
- **손글씨 인식**: 글자별 다른 변형 패턴
- **음성 인식**: 화자별 다른 발음 특성

### 구현 시 고려사항

#### 1. 수치적 안정성
- **정규화**: 공분산 행렬의 조건수 개선
- **특이값 분해**: 역행렬 대신 SVD 사용
- **수축 추정**: James-Stein 타입 추정기 사용

#### 2. 차원의 저주
높은 차원에서 QDA의 문제점:
- 매개변수 수의 급격한 증가
- 공분산 행렬 추정의 어려움
- 과적합 위험 증가

해결 방법:
- **차원 축소**: PCA 등을 통한 전처리
- **특성 선택**: 중요한 특성만 선별
- **정규화**: Ridge 타입 정규화 적용

#### 3. 클래스 불균형
- **가중치 조정**: 클래스 크기에 따른 가중치
- **사전 확률**: 균형 잡힌 사전 확률 사용
- **샘플링**: 균형 잡힌 데이터셋 구성

### 성능 평가

#### 1. 모델 선택
교차 검증을 통한 LDA vs QDA 선택:
- **AIC/BIC**: 정보 기준으로 모델 비교
- **교차 검증 오차**: 일반화 성능 비교
- **학습 곡선**: 데이터 크기에 따른 성능 변화

#### 2. 가정 검증
- **정규성 검정**: Shapiro-Wilk, Anderson-Darling 테스트
- **동질성 검정**: Box의 M 테스트 (공분산 동질성)
- **독립성 검정**: 잔차 분석

### 확장 및 변형

#### 1. 비모수적 QDA
커널 밀도 추정을 이용한 QDA:
$$\hat{f}_k(x) = \frac{1}{n_k h^p} \sum_{i: y_i = k} K\left(\frac{x - x_i}{h}\right)$$

#### 2. 로버스트 QDA
이상치에 강한 QDA:
- **M-추정기**: 로버스트 위치 및 분산 추정
- **MCD**: 최소 공분산 결정자 사용

#### 3. 희소 QDA
고차원 데이터를 위한 희소성 가정:
- **Lasso 정규화**: L1 정규화를 통한 희소 공분산 행렬
- **그래프 라쏘**: 그래프 구조를 활용한 정규화

### 최적화 전략

#### 1. 계산 효율성
- **Cholesky 분해**: 공분산 행렬의 효율적 분해
- **캐싱**: 반복 계산 결과 저장
- **병렬 처리**: 클래스별 독립 계산

#### 2. 메모리 최적화
- **온라인 학습**: 스트리밍 데이터 처리
- **블록 처리**: 대용량 데이터의 배치 처리
- **압축**: 공분산 행렬의 저랭크 근사

QDA는 LDA보다 유연한 결정 경계를 제공하지만, 더 많은 매개변수와 강한 가정을 필요로 한다. 적절한 데이터 크기와 차원에서 사용할 때 뛰어난 성능을 보일 수 있으며, 정규화 기법을 통해 과적합을 방지하는 것이 중요하다. 실제 적용 시에는 데이터의 특성과 문제의 복잡도를 고려하여 LDA와 QDA 중 적절한 방법을 선택해야 한다.
