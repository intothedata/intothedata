# 데이터 플랫폼 (Data Platform)

데이터 플랫폼은 다양한 원천에서 생성되는 데이터를 수집, 저장, 처리, 분석, 시각화, 배포까지 전 주기를 지원하는 통합 시스템을 의미합니다. 데이터 플랫폼은 단순한 데이터베이스를 넘어, 대용량 데이터(빅데이터) 처리, 실시간 분석, 데이터 거버넌스, 보안, 확장성 등 현대 데이터 환경의 다양한 요구를 충족시키는 핵심 인프라입니다.

데이터 플랫폼의 주요 목적은 다음과 같습니다.
- 데이터를 안전하게 저장하고 효율적으로 관리
- 다양한 데이터 소스(내부/외부, 정형/비정형) 통합
- 대규모 데이터의 신속한 처리 및 분석 지원
- 데이터 기반 의사결정 및 비즈니스 인사이트 도출
- 데이터 접근성, 품질, 보안, 거버넌스 보장

## 데이터 플랫폼의 주요 유형

### 1. 빅데이터 기반 데이터 플랫폼

대용량 데이터의 저장과 분산처리, 대규모 분석을 지원하는 플랫폼입니다.

- **Hadoop**: 오픈소스 분산 파일 시스템(HDFS)과 맵리듀스 기반의 데이터 처리 프레임워크. 대용량 데이터 저장 및 배치 처리에 강점.
- **Hive**: Hadoop 위에서 동작하는 데이터 웨어하우스 솔루션. SQL 유사 언어(HiveQL)로 대규모 데이터 쿼리 가능.
- **Spark**: 인메모리 분산 데이터 처리 엔진. 빠른 데이터 분석과 머신러닝, 실시간 스트리밍 처리 지원.
- **Kafka**: 대용량 데이터의 실시간 스트리밍 및 메시지 큐 역할.

### 2. 클라우드 기반 데이터 플랫폼

클라우드 환경에서 제공되는 확장성 높은 데이터 저장, 처리, 분석 서비스로, 인프라 관리 부담을 줄이고 빠른 확장과 통합을 지원합니다.

#### 구글 클라우드(Google Cloud) 데이터 플랫폼 서비스

- **BigQuery**: 완전관리형 서버리스 데이터 웨어하우스. 대규모 데이터에 대한 초고속 SQL 쿼리 지원.
- **Dataflow**: 스트리밍 및 배치 데이터 처리 파이프라인 구축을 위한 완전관리형 서비스.
- **Dataproc**: Hadoop/Spark 기반 클러스터를 손쉽게 생성·운영할 수 있는 서비스.
- **Datastudio**: 데이터 시각화 및 대시보드 작성 도구.
- **Cloud Storage**: 대용량 객체 스토리지 서비스.

#### 아마존 웹서비스(AWS) 데이터 플랫폼 서비스

- **Amazon Redshift**: 완전관리형 데이터 웨어하우스. 대규모 데이터 분석에 최적화.
- **Amazon S3**: 확장성 높은 객체 스토리지. 데이터 레이크 구축의 핵심.
- **Amazon EMR**: Hadoop, Spark 등 오픈소스 빅데이터 프레임워크를 클라우드에서 손쉽게 운영.
- **AWS Glue**: 데이터 통합, ETL(추출·변환·적재) 자동화 서비스.

#### 기타 주요 클라우드 데이터 플랫폼

- **Microsoft Azure Synapse Analytics**: 데이터 통합, 분석, 머신러닝을 통합 제공.
- **Snowflake**: 멀티 클라우드 기반의 데이터 웨어하우스 및 데이터 공유 플랫폼.
- **Databricks**: Apache Spark 기반의 데이터 분석 및 AI 플랫폼.

---

데이터 플랫폼은 기업의 데이터 자산을 효과적으로 활용하고, 데이터 기반 혁신을 실현하는 데 필수적인 역할을 합니다. 각 플랫폼의 특성과 조직의 요구사항을 고려하여 적합한 솔루션을 선택하는 것이 중요합니다.
