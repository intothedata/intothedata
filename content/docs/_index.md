## 인투더데이터 - Into the data

“데이터에 몰입하기”라는 뜻이다.

인투더데이터(IntoTheData)는 데이터 사이언스 (Data Science, 데이터 과학) 학습을 위한 위키이다. 초보자부터 전문가까지 모든 수준의 학습자를 위한 지식 저장소이다. 이론적 기초부터 실무 적용까지, 데이터 과학의 전 영역을 자료를 지속적으로 업데이트하고 공개한다.

많은 사람들이 “데이터 사이언스를 쉽게 배우게 하는 것”이 이 위키의 목표다.

### 🎯 주요 특징

- **체계적인 학습 경로**: 기초부터 고급까지 단계별 학습 가이드
- **실무 중심 접근**: 이론과 실습의 균형잡힌 구성
- **최신 동향 반영**: 빠르게 변화하는 데이터 과학 트렌드 업데이트
- **다양한 참고자료**: 도서, 강의, 웹사이트, 도구 등 종합 정보

### 📚 주요 구성

- **기초 이론**: 통계학, 수학, 프로그래밍 기초
- **데이터 처리**: 수집, 정제, 변환, 저장 기법
- **분석 및 모델링**: 머신러닝, 딥러닝, 통계 분석
- **시각화**: 데이터 스토리텔링과 인사이트 전달
- **실무 도구**: Python, R, SQL, 클라우드 플랫폼
- **참고자료**: 추천 도서, 강의, 웹사이트, 주요 인물
